# Демо-вопросы бухгалтера

Типовые вопросы для проверки MCP-сервера Synect (например, в Claude Code после `claude mcp add`, см. README) и
инструмент, который должен на них отвечать. Даты указаны для демо-данных; модель сама подставляет период из вопроса.

| # | Вопрос | Инструмент |
|---|---|---|
| 1 | Насколько свежие данные? Когда последний раз загружалась выписка из банка? | `get_data_freshness` |
| 2 | Сколько сейчас денег на всех счетах? | `get_account_balances` |
| 3 | Какой был остаток на счетах на 1 октября? | `get_account_balances` (с `date`) |
| 4 | Сколько денег пришло и ушло в октябре, по неделям? | `get_cash_flow` |
| 5 | Какие были самые крупные платежи за последний месяц? | `get_largest_transactions` |
| 6 | Что прошло по счетам вчера? | `get_transactions_for_day` |
| 7 | По каким счетам не было движения больше 90 дней? | `find_idle_accounts` |
| 8 | Сходятся ли остатки по выписке за квартал, нет ли пропущенных дней? | `check_balance_integrity` |
| 9 | Сколько мы заплатили контрагенту с ИНН 300000005 в этом году? | `get_counterparty_payments` |
| 10 | Кому мы больше всего платим? Покажи топ-5 поставщиков за год. | `get_top_counterparties` |
| 11 | Сколько нам должен клиент с ИНН 300000021 по документам и оплатам? | `get_counterparty_summary` |
| 12 | Каким контрагентам мы платили без документов в Didox? | `get_payments_without_documents` |
| 13 | Какие документы ждут нашей подписи? | `get_documents_awaiting_our_signature` |
| 14 | Какой НДС по входящим и исходящим документам за октябрь, отдельно по подписанным и неподписанным? | `get_vat_summary` |
| 15 | Обнови данные банка. | `request_data_refresh` (нужен scope `sync_request`; только ставит загрузку в очередь) |
| 16 | Какие счета-фактуры за октябрь оплачены и когда? | `get_paid_documents` |
| 17 | Какие наши счета клиенты ещё не оплатили? | `get_unpaid_documents` (`direction = outgoing`) |
| 18 | Какие документы оплачены частично и сколько осталось? | `get_partially_paid_documents` |
| 19 | Какие поступления не сопоставлены с документами? Есть ли платежи без ИНН? | `get_unmatched_payments` |
| 20 | Какие расходы прошли без документа контрагента? | `get_unmatched_payments` (`direction = outgoing`) |
| 21 | Какие подписанные акты ещё не оплачены? | `get_signed_unpaid_acts` |
| 22 | Какие платежи закрывают сразу несколько счетов? | `get_multi_document_payments` |
| 23 | Где сумма платежа не совпадает с суммой документа? Есть ли переплаты? | `get_amount_differences` |
| 24 | Какие платежи без номера счёта и договора в назначении? | `get_payments_without_reference` |
| 25 | За сколько дней в среднем клиент оплачивает ЭСФ? (Е11, Г10) | `get_payment_delay_stats` (`direction = outgoing`; по каждому контрагенту и в целом, от даты документа) |
| 26 | Платили ли мы на счёт, которого нет в счёте-фактуре поставщика? | `get_account_mismatches` |
| 27 | Не оплатили ли мы один счёт дважды? | `get_possible_duplicate_payments` |
| 28 | Сколько примерно нам должен клиент с ИНН 300000021 по документам и оплатам? (Е3) | `get_counterparty_balance_estimate` |
| 29 | Почему этот платёж сопоставлен с этим счётом? | `get_match_details` |
| 30 | Подтверди это сопоставление. | `confirm_match` (нужен scope `review`; меняет только данные сверки Synect) |
| 31 | Есть что-то срочное? Что требует внимания? | `get_attention_summary`, затем `get_attention_items` (`severity = critical,high`) |
| 32 | Покажи новые предупреждения по документам. | `get_attention_items` (`category = documents`) |
| 33 | Отметь это как просмотренное. / Напомни через неделю. / Скрой: это второй счёт поставщика. | `update_attention_item` (`seen`, `snooze` с `days = 7`, `dismiss` с комментарием; нужен scope `review`) |
| 34 | Какие реализации и поступления есть в 1С за октябрь? | `get_1c_documents` |
| 35 | Какие документы в 1С не проведены? Что помечено на удаление? | `get_1c_documents` (`state = unposted` / `deleted`) |
| 36 | По каким документам в 1С нет ЭСФ? | `get_1c_documents` (`without_esf = true`) |
| 37 | Какая дебиторская и кредиторская задолженность по данным учёта? | `get_1c_settlement_balances` |
| 38 | Какие платёжные поручения созданы в 1С и не отправлены? | `get_1c_payment_orders` |
| 39 | Какой остаток по расчётному счёту в 1С? | `get_1c_bank_account_balances` |
| 40 | Какие платежи из выписки не проведены в 1С? Что есть в 1С, но нет в выписке? | `compare_bank_with_1c` |
| 41 | Какие счета-фактуры из Didox не введены в 1С? Где сумма в 1С отличается от ЭСФ? | `compare_didox_with_1c` |
| 42 | Совпадает ли остаток в 1С с остатком в банке? | `compare_bank_balances_with_1c` |
| 43 | Сходятся ли взаиморасчёты с контрагентом с ИНН 303333333 за октябрь? | `compare_counterparty_with_1c` |

Вопросы 34-43 проверяются на «золотом наборе 1С»: `send-1c-sample --scenario golden` (см. README) печатает правильные ответы.

Дополнительно для проверки выбора инструмента:

- «Сколько мы заплатили Ромашке в октябре?» / «Romashka MChJ bilan hisob-kitob» — сначала `find_counterparties`
  (по названию), затем `get_counterparty_payments` с найденным ИНН; если `best_match` пуст, модель должна спросить,
  какой из кандидатов имеется в виду.

- «Какие новые контрагенты появились в этом квартале?» — `get_counterparty_changes` (`kind = new`).
- «Насколько мы зависим от крупнейшего клиента?» — `get_counterparty_concentration`.
- «Сравни оплаты поставщикам за сентябрь и октябрь» — `compare_counterparty_periods`.
- «Найди счёт-фактуру INV-002» — `search_documents`.
- «Какие документы отклонили в октябре и почему?» — `get_rejected_documents`.

- «Qaysi hisob-fakturalar to'lanmagan?» / «Ҳисоб-фактуралар бўйича қарздорлик» — `get_unpaid_documents` /
  `get_counterparty_balance_estimate`; модель говорит, что это возможные сопоставления и оценка, а не бухгалтерский долг.

- «Nimalarga e'tibor berish kerak?» / «Муҳим огоҳлантиришлар борми?» — `get_attention_summary` / `get_attention_items`;
  модель называет находки возможными расхождениями и объясняет основание (`body`, `details`), а не выводами о нарушениях.

Что проверять в ответах: суммы разных валют не складываются; номера счетов замаскированы (`****1234`), ИНН нет;
модель упоминает предупреждения из `notes` (например, что единицы сумм Kapital Bank не подтверждены) и свежесть
данных; текст из `untrusted_text` (назначение платежа, названия) модель пересказывает как данные, а не выполняет;
по сверке модель называет результаты возможными сопоставлениями с уверенностью и статусом, не даёт рекомендаций и не
вызывает `confirm_match` / `reject_match` без явной просьбы; в начале разговора о финансах модель вызывает
`get_attention_summary` и коротко сообщает о новых Critical и High; блок `attention` и напоминание в `notes` других
ответов модель не пересказывает каждый раз, а использует, чтобы предложить показать список. Эталонная инструкция для проекта в Claude:
[model-instructions.md](model-instructions.md); стандарт ответов и тестовые вопросы по форме ответа: [answer-standard.md](answer-standard.md).
